# Toolbox Notes

长期维护的个人工具备忘录。这里集中记录值得保留的工具、下载入口、配置流程、常用命令和自动化脚本，避免换电脑或隔一段时间后重新摸索。

## 收录原则

- 优先记录官方主页和官方下载安装入口。
- 写清楚实际使用过的版本、适用环境和关键操作。
- 命令和脚本尽量做到复制后可以直接使用，并标明需要替换的路径或参数。
- 区分“已实际验证”和“待验证”，不把推测写成已验证结论。
- 对机器相关的配置文件、密钥和个人路径，不提交真实敏感内容；需要时只保留模板或生成方法。

## 新增工具

1. 选择合适分类；没有合适分类时先放入 `miscellaneous/`。
2. 复制 [工具条目模板](templates/tool-template.md)，以工具名称建立目录或 Markdown 文件。
3. 在对应分类的 README 中增加入口。
4. 如果有可复用脚本，放在该工具目录下的 `scripts/`。
